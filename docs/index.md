# NHS Common User Interface source guidance

An independent restoration of the NHS Common User Interface (CUI) design guidance, retaining extracted illustrations and links to the original PDFs.

Use the navigation or search to explore the collection. [Read the preservation notes](preservation.md) before relying on a transcription or reusing its contents.

## Source guidance and working controls

This archive preserves historical guidance. It is not a competing component library and does not certify a clinical system as safe or compliant.

[Gabe Rijpma's Common User Interface](https://github.com/giussepe198/common-user-interface) implements the guidance as React and TypeScript controls, with additional Australian and New Zealand behaviour. The two projects are complementary: illustrated source material here, distilled rules and working controls there.

## Historical material, not current clinical policy

The original guidance includes legacy terminology, superseded references, fictional examples and consultation documents. Transcription can introduce errors, especially in tables. Use the source PDF to resolve uncertainty, check current standards and perform the clinical safety assessment required for your implementation.

This project is not endorsed by the NHS or Microsoft. Original documents and illustrations retain their original rights and attribution.
