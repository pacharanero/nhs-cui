# Reading the original guidance

The navigation groups the restored guidance by subject. Each transcription retains its extracted images and a link to the original PDF. Search can find phrases and guideline identifiers across the collection.

These pages are transcriptions, not rewritten guidance. Original "correct" and "incorrect" illustrations are historical examples, not a requirement to reproduce their old visual styling. Some extraction artefacts remain; consult the source PDF when interpreting tables, figures or a disputed rule.

The archive retains two byte-identical downloads of the full patient-banner guide (`patben` and `patben-2`). The original link manifest labels one as a quick guide, but its downloaded contents are not a distinct quick implementation guide. The navigation labels that duplicate explicitly rather than repeating the misleading title.

See [preservation and terms](../preservation.md) for source provenance and redistribution caveats.
